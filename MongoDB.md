# Workato

As a Technical Writer at MongoDB, I work on documentation content for all our officially supported drivers and connectors. In addition to creating content from the ground up for new features, I also work on maintenance tasks across all drivers, but with a special focus on the JVM and Node drivers.

The following documentation samples are some examples of my day-to-day writing tasks. Each page was written from scratch, and I also was fully responsible for writing and testing all code samples:

* [C++ Vector Search](https://shuangela.github.io/portfolio/CPP-Vector-Search.pdf)
* [Hibernate ORM Entities](https://shuangela.github.io/portfolio/Hibernate-Entities.pdf)

In addition to the documentation samples above, I contributed to a MongoDB Python sample app using Python FastAPI as the backend. This app is intended to showcase fundamental MongoDB concepts to new users.

* [MongoDB Sample Mflix Appliccation](https://github.com/mongodb/sample-app-python-mflix)
